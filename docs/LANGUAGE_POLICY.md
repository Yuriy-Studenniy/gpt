# Язык документации и исходного кода

Основной язык проекта — русский.

## Обязательные правила

- README, инструкции по установке и запуску, архитектурные документы, планы,
  описания этапов и пользовательские диагностические сообщения пишутся по-русски.
- Комментарии и docstring в новом коде пишутся по-русски, если они объясняют
  поведение проекта человеку.
- Имена файлов, модулей, функций, классов и переменных в Python/Lua остаются
  английскими: это стандартная техническая практика и часть стабильного API.
- Имена полей JSON, SQL-колонок, операций протокола, CLI-флагов и значений enum
  остаются английскими, потому что это машинный контракт между компонентами.
- Внешние названия библиотек и технологий (Python, SQLite, X-Ray, LLM, IPC)
  не переводятся.
- Если строка ошибки предназначена для пользователя проекта, текст ошибки
  должен быть русским. Имена полей и кодов ошибок при этом можно сохранить
  английскими для диагностики и совместимости.

## Проверка перед фиксацией

Перед commit проверь, что новый README и вся объяснительная документация
написаны по-русски, а новые комментарии/docstring не оставлены на английском
без технической причины. Не переводить программные идентификаторы и поля
протокола механически: их стабильность важнее буквального перевода.
