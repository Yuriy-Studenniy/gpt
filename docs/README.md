# Документация AI Stalker Companion

Эта папка — постоянная точка сохранения контекста разработки между чатами.

## Установка в игру

- **[INSTALLATION.md](INSTALLATION.md)** — пошаговая установка в CoP 1.6.02 с точными путями и списком файлов. Не копируй весь плоский репозиторий в игру.

## С чего начинать при продолжении работы

1. **[PROJECT_STATUS.md](PROJECT_STATUS.md)** — актуальный статус, цель проекта, принципы архитектуры, этапы разработки, известные долги и следующий приоритет. Читать первым.
2. **[WORLD_MODEL_DESIGN.md](WORLD_MODEL_DESIGN.md)** — текущая архитектура главы 2: каталог мира, факты движка и знания компаньона.
3. **[DEVELOPMENT_DIARY.md](DEVELOPMENT_DIARY.md)** — хронология аудита и решений: что найдено, почему принято решение, что изменено, какие риски остались и какие проверки выполнены.
4. **[CHAPTER_1_FINAL_AUDIT.md](CHAPTER_1_FINAL_AUDIT.md)** — заключительная статическая сверка: что реализовано, где есть ограничения и что осталось подтвердить.
5. **[IN_GAME_TEST_CHECKLIST.md](IN_GAME_TEST_CHECKLIST.md)** — единый чек-лист для одного комплексного теста главы 1 в CoP 1.6.02; не просить пользователя проходить его частями.

## Обязательные правила ведения проекта

- Проверять актуальную ветку `main` и текущие исходники; не считать прошлую запись дневника доказательством, что код не изменился.
- После существенной правки фиксировать в дневнике причину, затронутые файлы, коммит, результат статической проверки и открытые вопросы.
- Различать найденный код, статическую проверку, подтверждение по API и проверку в самой игре.
- Не требовать искусственно воспроизводить редкие состояния в начале прохождения. Оставшиеся проверки главы 1 выполнять по мере естественной игры или при появлении симптомов; перед проверкой лечению/потребностей сначала обеспечить диагностику фактических значений.
- Целевая среда — S.T.A.L.K.E.R.: Call of Pripyat 1.6.02 на оригинальном X-Ray. Не переносить предположения об OpenXRay без отдельной проверки.
- `gui-AI` и `MSC-port` — источники идей, а не готовые шаблоны. Не копировать их архитектуру или прежнего персонажа V-103.
